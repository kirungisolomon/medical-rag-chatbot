# Medical RAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that allows users to ask questions about medical documents using Large Language Models, LangChain, and Pinecone vector search.

## Features

- Document ingestion
- Text chunking
- Vector embeddings
- Semantic search using Pinecone
- Context-aware responses using LLMs
- Medical knowledge retrieval

## Tech Stack

- Python
- LangChain
- Pinecone
- OpenAI API
- Vector Embeddings
- FastAPI (coming later)
