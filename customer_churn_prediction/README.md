# Customer Churn Prediction

An end-to-end data science project for predicting customer churn from structured customer data.

## Scope

- Data validation and cleaning
- Exploratory data analysis
- Feature engineering
- Classification model training
- Model evaluation
- Reusable prediction pipeline

## Prediction pipeline

The pipeline will combine preprocessing and the trained classifier so new customer records receive a churn probability and a final churn decision using the same transformations used during training.
